# Claude Code — instrucciones de este repositorio

Leé primero `AGENTS.md` en la raíz del repositorio: contiene la regla de oro del proyecto (no romper comportamiento de producción sin avisar) y las reglas concretas para tocar autenticación, permisos y servido de archivos.
